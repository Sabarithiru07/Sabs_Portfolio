Overview

I design and build websites that look right on every screen. Drawing on my freelance full-stack work and a UI/UX design course, I take a site from wireframes and high-fidelity Figma prototypes through development, testing and deployment, so you work with one person from idea to launch.

What you get

Responsive layouts that adapt to mobile, tablet and desktop

Figma wireframes and high-fidelity prototypes agreed before development starts

A clean front end in HTML5, CSS3 and JavaScript

A Django (or PHP) backend for forms, content and data, with MySQL for storage

Git-based version control and a tested, deployed site

How we work together

  1. 1

    Requirement gathering

    We agree the goals, pages, content and features the site needs.

  2. 2

    UI/UX design

    Wireframes and high-fidelity prototypes in Figma, reviewed before any code is written.

  3. 3

    Development

    A responsive front end and, where needed, a Django backend with a MySQL database.

  4. 4

    Testing

    Checks across screen sizes, plus forms and data flows.

  5. 5

    Deployment

    The site goes live and is handed over with the source in Git.
